# Friendship Day App for Vihar 🎉

A beautiful, production-ready Streamlit web application to celebrate Friendship Day with Vihar. Visitors can enter their name, upload memorable photos, and receive a personalised slideshow video, or enjoy an interactive celebration page.

## ✨ Features

- Elegant landing page with balloons, confetti, and glassmorphism UI
- Persistent visitor tracking using CSV database
- Personalised experience: new vs returning visitors
- Photo upload (3–5 images) with automatic video generation
  - Ken Burns effect, crossfade transitions, text overlays
  - Soft background music (silent placeholder)
- "No photos" celebration page with animations, hearts, and friendship quote
- Video preview and download option
- Fully responsive, premium UI/UX

## 🚀 Deployment to Streamlit Community Cloud

1. **Download** this entire project folder.
2. **Upload** it to a new GitHub repository.
3. Go to [Streamlit Community Cloud](https://streamlit.io/cloud).
4. Click **"New app"** and connect your GitHub repository.
5. Set **Main file path** to `app.py`.
6. Click **Deploy**.

The app will be live in seconds – no additional configuration needed.
